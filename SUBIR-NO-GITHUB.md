# Subir este repositório no GitHub

O repositório já vem com o histórico do git (pasta `.git`). Falta só criar o repositório vazio no GitHub e enviar.

1. No GitHub, crie um repositório novo chamado `field-shift`, **privado**, sem README, sem .gitignore e sem licença.
2. No terminal, dentro desta pasta:

```bash
git remote add origin https://github.com/isaquebbncarvalho/field-shift.git
git push -u origin main
```

3. Para o time acessar: no repositório, Settings → Collaborators → adicionar cada pessoa. Ou deixe público no fim, se o envio do Space Apps exigir.

Depois de subir, pode apagar este arquivo.
