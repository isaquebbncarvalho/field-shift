# Como montar o projeto "hackaton" no claude.ai

1. Crie um projeto novo no claude.ai chamado **hackaton**.
2. Cole o conteúdo de `instrucoes-do-projeto.md` nas instruções do projeto.
3. Adicione estes arquivos ao conhecimento do projeto:
   - `README.md`
   - `CLAUDE.md`
   - `docs/proposta.md`
   - `docs/desafio.md`
   - `docs/metodo.md`
   - `docs/validacao.md`
   - `docs/checklist-evento.md`
   - `docs/pitch.md`
   - `data/conhecimento/culturas.json`
4. Se o projeto oferecer conexão com o GitHub, adicione o repositório `field-shift` também, para que o Claude leia o código atualizado.
5. Abra uma conversa nova no projeto e envie o texto de `prompt-inicial.md`.

Quando mudar algo importante no repositório (validação, valores agronômicos), atualize o arquivo correspondente no projeto.
