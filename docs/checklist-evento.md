# Checklist do evento

## Antes de sair de casa (sábado cedo)

- [ ] Notebook carregado, carregador e extensão.
- [ ] Repositório clonado no notebook: `git clone https://github.com/isaquebbncarvalho/field-shift.git`
- [ ] `setup/setup.ps1` rodado: testes passando e app abrindo.
- [ ] Claude Code logado e os MCPs aprovados (ver `setup/ferramentas.md`).
- [ ] Conta no Earthdata Login criada (só se for usar dados além do POWER).
- [ ] Celular com dados móveis para roteador de reserva.

## Primeira hora no evento

- [ ] Confirmar o desafio com o time e registrar a equipe no site do Space Apps.
- [ ] Dividir papéis: dados, regras e validação, app, pitch.
- [ ] Rodar o app na frente do time e combinar o que muda.
- [ ] Confirmar com a organização: tempo de apresentação, regra de uso de IA, se o repositório precisa ser público.

## Sábado

- [ ] Manhã: escopo fechado, base agronômica em revisão.
- [ ] Tarde: valores de `culturas.json` validados com fonte; conferência com o ZARC (`docs/validacao.md`).
- [ ] Noite: app de ponta a ponta com os ajustes do time. Dormir.

## Domingo

- [ ] Manhã: acabamento visual (Impeccable), vídeo de reserva gravado (tela + narração, 30 s a 2 min).
- [ ] Início da tarde: parar de construir. Ensaiar o pitch duas vezes cronometrado.
- [ ] Enviar o projeto na plataforma do Space Apps antes do prazo, com link do repositório e do vídeo.
- [ ] Tornar o repositório público se o envio exigir.

## Na hora da demo

- [ ] App aberto antes de chamar a banca, com Rio Verde selecionado.
- [ ] Vídeo de reserva aberto em outra aba.
- [ ] Não depender de internet: usar os municípios de exemplo.
